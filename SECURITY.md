# Security Policy

## Supported Versions

We take security seriously. Security updates will be provided for the 
latest stable version of each project.

## Reporting a Vulnerability

**Please do NOT open public issues for security vulnerabilities.**

If you discover a security vulnerability, please report it responsibly:

- 📧 **Email:** security@layraga.com
- 🔒 **GitHub:** Use the "Report a vulnerability" tab in the repo

We will:

- Acknowledge your report within **48 hours**
- Provide an estimated timeline for a fix
- Credit you in the release notes (if you wish)

Thank you for helping keep LAYRAGA OFFICIAL projects safe! 🔐
